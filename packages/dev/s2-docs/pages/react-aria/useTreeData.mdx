# useTreeData

<PageDescription>{docs.exports.useTreeData.description}</PageDescription>

`useTreeData` manages an immutable tree with helper methods to efficiently insert, move, update, and remove items. Updating the tree automatically causes the component to re-render.

It also manages selection based on unique item keys, and updates the selection automatically when items are removed.

## Example

```tsx
import {useTreeData} from 'react-stately/useTreeData';

let tree = useTreeData({
  initialItems: [
    {
      id: 'people',
      name: 'People',
      children: [
        {id: 'david', name: 'David'},
        {id: 'sam', name: 'Sam'}
      ]
    }
  ],
  getChildren: item => item.children || []
});

<Tree
  items={tree.items}
  selectedKeys={tree.selectedKeys}
  onSelectionChange={tree.setSelectedKeys}>
  {item => <TreeItem title={item.value.name} />}
</Tree>
```
