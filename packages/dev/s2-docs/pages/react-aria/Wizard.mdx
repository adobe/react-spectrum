By default, the steps before the current step are completed. Users move forward with the next button, and can go back to a completed step, which marks the steps after it as not completed. To validate each step before moving forward, wrap the wizard in a [Form](Form), and move to the next step when the form is submitted. The browser only submits the form when the fields in the current step are valid. Otherwise, it displays the errors and focuses the first invalid field.

This example creates a project with a field on each step. Panels are unmounted when their step is not current, so the values are stored in state. The example controls `selectedKey` so that the next button can create the project on the last step, while leaving completion uncontrolled.

## Content

`WizardStepList` and `WizardPanels` follow the [Collection Components API](collections?component=WizardStepList), accepting both static and dynamic collections. This example shows a dynamic collection, passing a list of objects to the `items` prop, and a function to render the children.

```tsx render
"use client";
import {Wizard, WizardStepList, WizardStep, WizardPanels, WizardPanel, WizardButtons} from 'vanilla-starter/Wizard';

let steps = [
  {id: 'account', label: 'Account', content: 'Choose a username and password.'},
  {id: 'profile', label: 'Profile', content: 'Add a photo and a short bio.'},
  {id: 'settings', label: 'Settings', content: 'Choose which notifications you receive.'},
  {id: 'confirm', label: 'Confirm', content: 'Check your details, then create your account.'}
];

<Wizard>
  <WizardStepList
    aria-label="Sign up"
    /*- begin highlight -*/
    items={steps}>
    {/*- end highlight -*/}
    {step => <WizardStep>{step.label}</WizardStep>}
  </WizardStepList>
  <WizardPanels
    /*- begin highlight -*/
    items={steps}>
    {/*- end highlight -*/}
    {step => <WizardPanel>{step.content}</WizardPanel>}
  </WizardPanels>
  <WizardButtons />
</Wizard>
```

## Current step

Use the `defaultSelectedKey` or `selectedKey` prop to set the current step. The selected key corresponds to the `id` prop of a `<WizardStep>`. By default, steps before the current step are marked as completed, and steps after it are disabled. Use the `data-current` and `data-completed` attributes to style them.

```tsx render
"use client";
import type {Key} from 'react-aria-components/Wizard';
import {Wizard, WizardStepList, WizardStep, WizardPanels, WizardPanel, WizardButtons} from 'vanilla-starter/Wizard';
import {useState} from 'react';

function Example() {
  let [step, setStep] = useState<Key>('members');

  return (
    <div style={{maxWidth: '100%'}}>
      <Wizard
        ///- begin highlight -///
        selectedKey={step}
        onSelectionChange={setStep}
        ///- end highlight -///
      >
        <WizardStepList aria-label="Create project">
          <WizardStep id="details">Details</WizardStep>
          <WizardStep id="members">Members</WizardStep>
          <WizardStep id="review">Review</WizardStep>
        </WizardStepList>
        <WizardPanels>
          <WizardPanel id="details">Name your project and choose who can see it.</WizardPanel>
          <WizardPanel id="members">Invite people to work on the project with you.</WizardPanel>
          <WizardPanel id="review">Check the details, then create the project.</WizardPanel>
        </WizardPanels>
        <WizardButtons />
      </Wizard>
      <p>Current step: {step}</p>
    </div>
  );
}
```

Buttons with `slot="previous"` and `slot="next"` move to the previous and next steps, skipping disabled steps. 
They can be placed anywhere inside the `Wizard`, and are disabled when there is no previous or next step.

## Completed steps

Wizards can work in two different ways, linearly, where steps must be completed in order, although you can visit previous steps. 
In this mode, users cannot skip ahead to incomplete steps and any steps after the last completed step plus one are disabled. 
Or non-linearly, where users can navigate freely between steps at any time and you are responsible for tracking which steps are completed and disabled.

### Controlled linear

Set `completedKeys` to decide which steps are completed, for example once a step's fields are valid, or to restore saved progress. 
Users can select the steps up to and including the one after the last completed step, and the next button is disabled until the current step is completed. 
Completed steps stay completed when users go back. Complete steps in order, so that users can't skip ahead of a step that isn't completed.

```tsx render files={["packages/dev/s2-docs/pages/react-aria/ProjectFields.tsx"]}
"use client";
import type {Key} from 'react-aria-components/Wizard';
import {Wizard, WizardStepList, WizardStep, WizardPanels, WizardPanel} from 'vanilla-starter/Wizard';
import {Button} from 'vanilla-starter/Button';
import {NameField, EmailField, Summary, isValidName, isValidEmail} from './ProjectFields';
import {useState} from 'react';

function Example() {
  let [step, setStep] = useState<Key>('details');
  let [name, setName] = useState('');
  let [email, setEmail] = useState('');

  /*- begin highlight -*/
  // A step is completed once its field is valid, and the steps before it are completed.
  let completedKeys: Key[] = [];
  if (isValidName(name)) {
    completedKeys.push('details');
    if (isValidEmail(email)) {
      completedKeys.push('members');
    }
  }
  /*- end highlight -*/

  return (
    <Wizard
      selectedKey={step}
      onSelectionChange={setStep}
      ///- begin highlight -///
      completedKeys={completedKeys}
      ///- end highlight -///
    >
      <WizardStepList aria-label="Create project">
        <WizardStep id="details">Details</WizardStep>
        <WizardStep id="members">Members</WizardStep>
        <WizardStep id="review">Review</WizardStep>
      </WizardStepList>
      <WizardPanels>
        <WizardPanel id="details">
          <NameField value={name} onChange={setName} />
        </WizardPanel>
        <WizardPanel id="members">
          <EmailField value={email} onChange={setEmail} />
        </WizardPanel>
        <WizardPanel id="review">
          <Summary name={name} email={email} />
        </WizardPanel>
      </WizardPanels>
      <div className="wizard-buttons">
        <Button slot="previous" variant="secondary">Back</Button>
        {step === 'review'
          ? <Button onPress={() => alert(`Created ${name}!`)}>Create project</Button>
          : <Button slot="next">Next</Button>}
      </div>
    </Wizard>
  );
}
```

### Controlled any order

Set `allowsRandomAccess` to let users select any step, in any order. 
Steps are only completed when they are in `completedKeys`, so users can see which steps still need their attention. 
Users can reach the last step at any time, so check that every step is completed before creating the project.

```tsx render files={["packages/dev/s2-docs/pages/react-aria/ProjectFields.tsx"]}
"use client";
import type {Key} from 'react-aria-components/Wizard';
import {Wizard, WizardStepList, WizardStep, WizardPanels, WizardPanel} from 'vanilla-starter/Wizard';
import {Button} from 'vanilla-starter/Button';
import {NameField, EmailField, Summary, isValidName, isValidEmail} from './ProjectFields';
import {useState} from 'react';

function Example() {
  let [step, setStep] = useState<Key>('details');
  let [name, setName] = useState('');
  let [email, setEmail] = useState('');

  /*- begin highlight -*/
  // Each step is completed once its field is valid, in any order.
  let completedKeys: Key[] = [];
  if (isValidName(name)) {
    completedKeys.push('details');
  }
  if (isValidEmail(email)) {
    completedKeys.push('members');
  }
  /*- end highlight -*/

  return (
    <Wizard
      selectedKey={step}
      onSelectionChange={setStep}
      ///- begin highlight -///
      allowsRandomAccess
      completedKeys={completedKeys}
      ///- end highlight -///
    >
      <WizardStepList aria-label="Create project">
        <WizardStep id="details">Details</WizardStep>
        <WizardStep id="members">Members</WizardStep>
        <WizardStep id="review">Review</WizardStep>
      </WizardStepList>
      <WizardPanels>
        <WizardPanel id="details">
          <NameField value={name} onChange={setName} />
        </WizardPanel>
        <WizardPanel id="members">
          <EmailField value={email} onChange={setEmail} />
        </WizardPanel>
        <WizardPanel id="review">
          <Summary name={name} email={email} />
        </WizardPanel>
      </WizardPanels>
      <div className="wizard-buttons">
        <Button slot="previous" variant="secondary">Back</Button>
        {step === 'review'
          ? <Button isDisabled={completedKeys.length < 2} onPress={() => alert(`Created ${name}!`)}>Create project</Button>
          : <Button slot="next">Save</Button>}
      </div>
    </Wizard>
  );
}
```
