## Content

`ProgressList` follows the [Collection Components API](collections?component=ProgressList), accepting both static and dynamic collections. This example shows a dynamic collection, passing a list of objects to the `items` prop, and a function to render the children.

```tsx render
"use client";
import {ProgressList, ProgressListItem} from 'vanilla-starter/ProgressList';

let steps = [
  {id: 'account', label: 'Account'},
  {id: 'profile', label: 'Profile'},
  {id: 'settings', label: 'Settings'},
  {id: 'confirm', label: 'Confirm'}
];

<ProgressList
  aria-label="Sign up"
  /*- begin highlight -*/
  items={steps}
  /*- end highlight -*/
  selectedKey="profile">
  {step => <ProgressListItem>{step.label}</ProgressListItem>}
</ProgressList>
```

## Current step

Use the `selectedKey` prop to set the current step. The current step is marked with `aria-current="step"`, and the steps before it are marked as completed. Use the `data-current` and `data-completed` attributes to style them.

```tsx render
"use client";
import {ProgressList, ProgressListItem} from 'vanilla-starter/ProgressList';
import {Button} from 'vanilla-starter/Button';
import {useState} from 'react';

let steps = [
  {id: 'cart', label: 'Cart'},
  {id: 'shipping', label: 'Shipping'},
  {id: 'payment', label: 'Payment'},
  {id: 'review', label: 'Review'}
];

function Example() {
  let [index, setIndex] = useState(1);

  return (
    <div style={{display: 'flex', flexDirection: 'column', alignItems: 'start', gap: 16, maxWidth: '100%'}}>
      <ProgressList
        aria-label="Checkout"
        items={steps}
        /*- begin highlight -*/
        selectedKey={steps[index].id}>
        {/*- end highlight -*/}
        {step => <ProgressListItem>{step.label}</ProgressListItem>}
      </ProgressList>
      <div style={{display: 'flex', gap: 8}}>
        <Button isDisabled={index === 0} onPress={() => setIndex(index - 1)}>Back</Button>
        <Button isDisabled={index === steps.length - 1} onPress={() => setIndex(index + 1)}>Next</Button>
      </div>
    </div>
  );
}
```

## ProgressList vs. Wizard

Use a `ProgressList` to show a sequence of steps in a user flow, where each step corresponds to a separate page or route.
To allow random access and let users move between the steps they have reached without losing their progress, use a [Wizard](Wizard) instead.
