## Content

`StepList` follows the [Collection Components API](collections?component=StepList), accepting both static and dynamic collections. This example shows a dynamic collection, passing a list of objects to the `items` prop, and a function to render the children.

```tsx render
"use client";
import {StepList, StepListItem} from 'vanilla-starter/StepList';

let steps = [
  {id: 'account', label: 'Account'},
  {id: 'profile', label: 'Profile'},
  {id: 'settings', label: 'Settings'},
  {id: 'confirm', label: 'Confirm'}
];

<StepList
  aria-label="Sign up"
  /*- begin highlight -*/
  items={steps}
  /*- end highlight -*/
  selectedKey="profile">
  {step => <StepListItem>{step.label}</StepListItem>}
</StepList>
```

### Links

Use the `href` prop on a `<StepListItemContent>` to create a link to a step. In this example, only completed steps are links, so users can go back to a previous step, but not skip ahead.

```tsx render files={["packages/dev/s2-docs/pages/react-aria/Router.tsx"]}
"use client";
import {StepList, StepListItem} from 'vanilla-starter/StepList';
import {Router, Link as RouterLink} from './Router';

<Router defaultSelectedRoute="/review">
  {({selectedRoute}) => (
    /*- begin highlight -*/
    <StepList aria-label="Checkout" selectedKey={selectedRoute} renderLink={props => <RouterLink {...props} />}>
      {/*- end highlight -*/}
      <StepListItem id="/cart" href="/cart">Cart</StepListItem>
      <StepListItem id="/shipping" href="/shipping">Shipping</StepListItem>
      <StepListItem id="/payment" href="/payment">Payment</StepListItem>
      <StepListItem id="/review" href="/review">Review</StepListItem>
    </StepList>
  )}
</Router>
```

By default, links are rendered as an `<a>` element. Use the `render` prop to integrate your framework's link component.

```tsx
<StepListItemContent
  href="/shipping"
  render={domProps =>
    'href' in domProps
      ? <RouterLink {...domProps} />
      : <div {...domProps} />
  } />
```

## Current step

Use the `selectedKey` prop to set the current step. The current step is marked with `aria-current="step"`, and the steps before it are marked as completed. Use the `data-current` and `data-completed` attributes to style them.

```tsx render
"use client";
import {StepList, StepListItem} from 'vanilla-starter/StepList';
import {Button} from 'vanilla-starter/Button';
import {useState} from 'react';

let steps = [
  {id: 'cart', label: 'Cart'},
  {id: 'shipping', label: 'Shipping'},
  {id: 'payment', label: 'Payment'},
  {id: 'review', label: 'Review'}
];

function Example() {
  let [index, setIndex] = useState(1);

  return (
    <div style={{display: 'flex', flexDirection: 'column', alignItems: 'start', gap: 16, maxWidth: '100%'}}>
      <StepList
        aria-label="Checkout"
        items={steps}
        /*- begin highlight -*/
        selectedKey={steps[index].id}>
        {/*- end highlight -*/}
        {step => <StepListItem>{step.label}</StepListItem>}
      </StepList>
      <div style={{display: 'flex', gap: 8}}>
        <Button isDisabled={index === 0} onPress={() => setIndex(index - 1)}>Back</Button>
        <Button isDisabled={index === steps.length - 1} onPress={() => setIndex(index + 1)}>Next</Button>
      </div>
    </div>
  );
}
```

## StepList vs. Wizard

Use a `StepList` to show the user's progress through a process where each step is a separate page or route.
To allow random access and let users move between the steps they have reached without losing their progress, use a [Wizard](Wizard) instead.
