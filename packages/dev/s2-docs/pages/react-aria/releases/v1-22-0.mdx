# v1.22.0

This release introduces `Sheet`, a swipeable overlay that slides in from the edge of the viewport and is built on native browser scroll gestures. 

(Add Sheet Example)

It also adds Turbopack support to `@react-aria/optimize-locales-plugin`, overlay placement that accounts for the virtual keyboard, and many bug fixes!

As always, many thanks to all of our contributors!

## Changelog

### General Changes
- Add `suppressHydrationWarning` to `GlobalDOMAttributes` so it can be forwarded by `filterDOMProps` - [@miszuto](https://github.com/miszuto) - [PR](https://github.com/adobe/react-spectrum/pull/10527)
- Fix `TypeError` in `preventFocus` when the window is focused or blurred during a press - [@microbit-matt-hillsdon](https://github.com/microbit-matt-hillsdon) - [PR](https://github.com/adobe/react-spectrum/pull/10592)
- Skips the visibility check in `Focusable` and `Pressable` development warnings so children inside hidden subtrees no longer warn - [@SimenB](https://github.com/SimenB) - [PR](https://github.com/adobe/react-spectrum/pull/10547)
- Throw an error on invalid `rgb()` and `rgba()` color strings - [@giaBaoJS](https://github.com/giaBaoJS) - [PR](https://github.com/adobe/react-spectrum/pull/10580)
- Enable the `useControlledState` early effect in React Native - [@su-jin1425](https://github.com/su-jin1425) - [PR](https://github.com/adobe/react-spectrum/pull/10550)
- Add support for interactive widgets, such as the virtual keyboard, when positioning overlays - [@nwidynski](https://github.com/nwidynski) - [PR](https://github.com/adobe/react-spectrum/pull/10102)
- Add Turbopack support to `@react-aria/optimize-locales-plugin` - [@stefanprobst](https://github.com/stefanprobst) - [PR](https://github.com/adobe/react-spectrum/pull/10462)
