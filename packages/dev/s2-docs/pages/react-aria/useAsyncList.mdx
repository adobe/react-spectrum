# useAsyncList

<PageDescription>{docs.exports.useAsyncList.description}</PageDescription>

`useAsyncList` extends [useListData](useListData), adding support for asynchronous loading, pagination, sorting, and filtering. It manages loading and error states, supports abortable requests, and works with any data fetching library or the browser [fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) API.

## Example

Pass a `load` function that returns the items to render. The provided abort signal should be passed to your request so it is canceled when a new load starts.

```tsx
import {useAsyncList} from 'react-stately/useAsyncList';

let list = useAsyncList({
  async load({signal}) {
    let response = await fetch('https://pokeapi.co/api/v2/pokemon', {signal});
    let json = await response.json();
    return {items: json.results};
  }
});

<ListBox
  items={list.items}
  loadingState={list.loadingState}>
  {item => <ListBoxItem>{item.name}</ListBoxItem>}
</ListBox>
```

For paginated APIs, return a `cursor` from `load` and call `list.loadMore` when the collection requests more data.
