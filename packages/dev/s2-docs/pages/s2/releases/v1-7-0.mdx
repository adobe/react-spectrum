# v1.7.0

## AI Components

We are excited to announce the first preview of React Spectrum's AI components to help build AI-powered experiences! Developed in close partnership with Spectrum design, this first batch of components covers the core of a chat interface, along with [documentation](../ai-components.mdx) to help you get started. 

<InstallCommand pkg="@react-spectrum/ai" />

### AI Icon

The new AI icon is now widely available and can be imported via:
<Command command="import AIMark from '@react-spectrum/s2/icons/AIMark';" />

## Icon size updates

Spectrum has updated the intended size of workflow icons relative to surrounding text. This is an intentional design update but it does mean icons may render at a different size from before post update. If you rely on visual regression tests, expect diffs around icon sizing and update your baselines accordingly.

## TypeScript

Types are now generated with TypeScript 7, so emitted `.d.ts` output may differ slightly.
