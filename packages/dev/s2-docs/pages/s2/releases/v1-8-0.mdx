# v1.8.0

This release introduces [SidePanel](../SidePanel), a component that wraps SideNav and other app chrome in a container that can collapse into a compact icon rail. 

```tsx render hideCode type="s2" dir="s2/releases" files={['packages/dev/s2-docs/pages/s2/SidePanelApp.tsx']}
"use client";
import {SidePanel, SideNav, SideNavItem, SideNavItemContent, SideNavItemLink, SideNavSection, SideNavHeader, Text} from '@react-spectrum/s2/SideNav';
import {SidePanelApp} from '../SidePanelApp';
import {style} from '@react-spectrum/s2/style' with {type: 'macro'};
import CCLibrary from '@react-spectrum/s2/icons/CCLibrary';
import Files from '@react-spectrum/s2/icons/Files';
import Images from '@react-spectrum/s2/icons/Images';
import Project from '@react-spectrum/s2/icons/Project';

<SidePanelApp defaultSelectedRoute="/files">
  {({selectedRoute}) => (
    /*- begin highlight -*/
    <SidePanel
      defaultCollapsed
      styles={style({gridArea: 'sidebar', width: 208, marginX: 8})}>
    {/*- end highlight -*/}
      <SideNav
        aria-label="Files"
        selectedRoute={selectedRoute}
        defaultExpandedKeys={['projects']}
        styles={style({width: 'full'})}>
        <SideNavItem href="/files" textValue="Files">
          <SideNavItemContent>
            <SideNavItemLink>
              <Files />
              <Text>Files</Text>
            </SideNavItemLink>
          </SideNavItemContent>
        </SideNavItem>
        <SideNavItem id="your-libraries" href="/your-libraries" textValue="Your Libraries">
          <SideNavItemContent>
            <SideNavItemLink>
              <CCLibrary />
              <Text>Your Libraries</Text>
            </SideNavItemLink>
          </SideNavItemContent>
          <SideNavItem href="/photos" textValue="Photos">
            <SideNavItemContent>
              <SideNavItemLink>
                <Images />
                <Text>Photos</Text>
              </SideNavItemLink>
            </SideNavItemContent>
          </SideNavItem>
        </SideNavItem>
        <SideNavSection>
          <SideNavHeader>Work</SideNavHeader>
          <SideNavItem id="projects" href="/projects" textValue="Projects">
            <SideNavItemContent>
              <SideNavItemLink>
                <Project />
                <Text>Projects</Text>
              </SideNavItemLink>
            </SideNavItemContent>
            <SideNavItem href="/projects/website" textValue="Website redesign">
              <SideNavItemContent>
                <SideNavItemLink>
                  <Text>Website redesign</Text>
                </SideNavItemLink>
              </SideNavItemContent>
            </SideNavItem>
            <SideNavItem href="/projects/mobile" textValue="Mobile app">
              <SideNavItemContent>
                <SideNavItemLink>
                  <Text>Mobile app</Text>
                </SideNavItemLink>
              </SideNavItemContent>
            </SideNavItem>
          </SideNavItem>
        </SideNavSection>
      </SideNav>
    </SidePanel>
  )}
</SidePanelApp>
```

It also adds [async loading](../Menu#asynchronous-loading) and [virtualization support](../Menu#virtualized-content) to Menu, and updates the TableView [column menu icon](../TableView#column-menus).

## AI Components:

This release introduces the new [AttachmentGrid](../ai-components#chat-threads) component for displaying collections of attachments, adds disabled state support to [Attachment](../ai-components#attachments-and-actions), and enables attachment-only submissions in PromptField. It also improves accessibility with updated PromptField ARIA labels, fine-tunes the visual layout of UserMessage with updated padding, and includes several bug fixes!

### Chat/Thread API Updates:
The Chat and Thread APIs have been simplified, with more styling now handled by the components rather than requiring custom styles. Components like ThreadScrollButton are now automatically included in the Thread and can be removed from your implementation. See the updated [documentation](../ai-components) for usage examples.
